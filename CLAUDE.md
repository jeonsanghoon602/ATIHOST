# Claude Instructions

Read and follow `AGENTS.md` before planning, editing, testing, reviewing, or creating a Pull Request.

When implementing an Issue:

1. Inspect the relevant code and report the expected files and scope.
2. Work only within the Issue requirements and acceptance criteria.
3. Use a separate branch or worktree and avoid files another agent is editing.
4. Run the relevant build and tests before reporting completion.
5. Report changed files, verification results, unverified conditions, and remaining risks.

Do not approve your own implementation as the final independent reviewer.
